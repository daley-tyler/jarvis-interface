# Source provenance

This repository contains the voice scripts and Python DAT modules from my existing JARVIS prototype, together with the documented reliability and privacy maintenance. The original project folder had no Git history. The publication history begins with an accurate import of the reviewed current source on 29 October 2026; it does not recreate earlier development dates. The separate local development history remains preserved.

The full visual prototype uses torinmb's MediaPipe TouchDesigner plugin and Google MediaPipe. The saved scene also contains an OpenPose component credited to Dotsimulate. Those remain separate upstream work and are not included here. I do not claim authorship of those frameworks or their example networks. The exact bundled component version and the source of several existing graphics and textures remain unresolved, which is why the scene and all visual assets are excluded. See [distribution](docs/DISTRIBUTION.md).

The October 2026 maintenance and documentation were prepared with Codex assistance. Tests use synthetic inputs; no personal recording, portrait or transcript is included. No source-code license is assigned by this repository.

The private scene's three-country panel tour is a demonstration of saved links, not identity recognition or real location tracking. Its legacy command name remains for compatibility. Removed personal media has not been restored for publication.
