# Source provenance

This local repository starts from the voice scripts and installed Python DATs in my existing JARVIS prototype. The source folder had no Git history, so the first commit records the files as found on 29 October 2026. It does not represent an earlier development history.

The visual scene uses torinmb’s MediaPipe TouchDesigner plugin and Google MediaPipe. Those components remain separate upstream work. The folder alone does not establish the exact authorship of every upgrade kit. The source of the bundled portraits, graphics, country texture, and audio still needs review before publication. The October 2026 maintenance changes were prepared with Codex assistance. No source license is assigned here while that review is open.

The saved scenes and installers were cleaned locally. Personal photographs, recording-derived audio, and raw runtime transcripts were removed rather than retained in backups. Generic assets preserve the interface’s expected file paths. Historical source code remains available without the original media. The source includes a legacy three-country portrait tour. It is a visual demonstration of saved links, not identity recognition or real location tracking.
